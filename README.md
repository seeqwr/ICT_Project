# Smart HR Assistant 🤖💼

## Жоба туралы (About the Project)
Бұл жоба — HR (адам ресурстары) мамандарының жұмысын автоматтандыруға және шешім қабылдау процестерін жеңілдетуге арналған ақылды веб-қосымша. Жобада жасанды интеллект алгоритмдері мен дерекқор біріктіріліп, пайдаланушыға ыңғайлы веб-интерфейс арқылы ұсынылған.

## Қолданылған технологиялар (Tech Stack)
- **Бэкенд:** Python (`server.py`)
- **Машиналық оқыту / AI:** Python (`model.py`)
- **Дерекқор:** SQLite (`hr.db`)
- **Фронтенд:** HTML, CSS, JavaScript

## Файлдық құрылым (Project Structure)
* `server.py` — қосымшаның негізгі бэкенд сервері (API бағыттаулары мен логикасы).
* `model.py` — HR мәліметтерін талдауға немесе болжауға арналған машиналық оқыту моделі.
* `hr.db` — қызметкерлер немесе үміткерлер туралы ақпарат сақталатын дерекқор.
* `requirements.txt` — жобаға қажетті тәуелділіктер мен Python кітапханаларының тізімі.
* `index.html` — басты веб-беттің негізгі құрылымы.
* `style.css` — веб-интерфейстің визуалды дизайны.
* `script.js` — фронтенд бөлігінің интерактивті логикасы.

## Іске қосу нұсқаулығы (How to Run)

**1. Жобаны дайындау**
Жоба файлдарын компьютерге жүктеп алып, терминалдан (CMD, PowerShell немесе Git Bash) жоба орналасқан папкаға өтіңіз.

**2. Қажетті кітапханаларды орнату**
`requirements.txt` файлында көрсетілген барлық тәуелділіктерді орнату үшін мына пәрменді орындаңыз:
```bash
pip install -r requirements.txt
```

**3. Серверді іске қосу**
Бэкенд серверін қосу үшін терминалда мына пәрменді теріңіз:
```bash
python server.py
```

**4. Қосымшаны ашу**
Браузерді ашып, терминалда көрсетілген жергілікті сілтемеге (мысалы, `http://localhost:5000` немесе `http://127.0.0.1:8000`) өтіңіз. Осы кезде `index.html` интерфейсі ашылуы тиіс.
